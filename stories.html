Room 4 / Evidence archive

Identify the alien signal

The archive contains three signal reports. Only one repeats the structure used by the launch transmission.

  • Report A: THAN-ZIE / LIN / DZEH
  • Report B: THAN-ZIE-LIN-DZEH
  • Report C: THAN-ZIE, LIN, DZEH

The correct structure uses spaces between code words and hyphens only inside a code word. Report C is correct; move its letter eleven places forward in the alphabet to get Hint 4.
