Room 6 / Escape pod

Enter the master command

The escape pod needs the captain's launch code. The earlier rooms taught you how to read it: Navajo code words, a 26-letter alphabet, preserved groups, and spaces between words.

Transmission:

THAN-ZIE LIN DZEH MOASI NE-AHS-JAH BE DZEH TKIN DIBEH DIBEH-YAZZIE WOL-LA-CHEE NO-DA-IH NESH-CHEE MOASI LIN

Use the 26-letter cipher to identify and verify each code word. Preserve the word order, spaces, and internal hyphens, then enter the complete launch code.

If all six rooms are solved, the station will release you.
