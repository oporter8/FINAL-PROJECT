Room 1 / Captain's quarters

A message in the stars

The captain left a note before disappearing. Read the first letter of each sentence. They are not a word: they are the first four entries in a phonetic alphabet.

Than-zie means the letter T.

Lin means the letter L.

Dzeh means the letter D.

Moasi means the letter M.

These are Navajo Code Talkers code words. Each word stands for the letter it begins with. Decode LIN and record the result as Hint 1.
