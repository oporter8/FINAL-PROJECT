Web Development Toolkit

Use these reference tables to learn the basic structures of HTML, CSS, and JavaScript.

HTML

HTML creates the structure and content of a webpage.

Structure What it does How to use it
<h1>...</h1>Creates a main heading.Use heading levels from h1 through h6 to organize sections.
<p>...</p>Creates a paragraph.Put regular written content between the opening and closing tags.
<a href="page.html">Link</a>Creates a link.Place the destination in href and the clickable text between the tags.
<img src="photo.jpg" alt="Description">Displays an image.Use src for the image path and alt to describe it.
<ul> <li>Item</li> </ul>Creates an unordered list.Wrap each list item in an li tag inside a ul.
<div>...</div>Groups content into a block.Use it to create a container that can be styled with CSS.
<section>...</section>Groups related content.Use it for meaningful page sections, usually with a heading.
<button>Click</button>Creates a clickable button.Use it for actions, such as running JavaScript.
<input type="text">Creates a form input.Choose an input type such as text, email, or checkbox.

CSS

CSS controls the appearance and layout of HTML elements.

Structure What it does How to use it
selector { property: value; }Creates a CSS rule.Choose an element, class, or ID, then set its styles inside the braces.
p { color: red; }Styles every paragraph.Use an element selector when the same style applies to all matching elements.
.card { padding: 1rem; }Styles elements with a class.Put a period before the class name and add class="card" in HTML.
#main { ... }Styles one element by ID.Put a hash before the ID name and add id="main" in HTML.
background-color: blue;Changes the background color.Use a color name, hex code, RGB value, or gradient.
margin: 1rem;Adds space outside an element.Use margin to separate an element from other elements.
padding: 1rem;Adds space inside an element.Use padding to create space between content and its border.
display: flex;Creates a flexible layout.Combine it with gap, justify-content, and align-items.
@media (max-width: 600px) { ... }Creates responsive styles.Put styles inside it to change the layout on smaller screens.

JavaScript

JavaScript adds behavior and interaction to a webpage.

Structure What it does How to use it
let name = "Alex";Stores a value in a variable.Use let when the value may change.
const color = "blue";Stores a value that should not be reassigned.Use const by default for values that stay the same.
function greet() { ... }Creates reusable code.Call the function by writing its name followed by parentheses.
if (condition) { ... }Runs code only when a condition is true.Put a comparison or Boolean expression inside the parentheses.
for (let i = 0; i < 3; i++) { ... }Repeats code.Use a loop when you need to run the same code multiple times.
document.querySelector(".card")Finds an HTML element.Use a CSS selector inside the parentheses.
element.textContent = "Hello";Changes text on the page.Store an element in a variable, then update its textContent.
button.addEventListener("click", function () { ... });Responds to an event.Attach it to an element and put the action inside the function.
console.log(value);Prints a value for debugging.Check the browser's developer console to see the result.
